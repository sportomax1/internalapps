Data Lab + Source Notes

Where useful fantasy data comes from, how to test it, and what to investigate next.

Sleeper Player Directory

OFFICIALNO AUTH

Master identity map. Use it to translate names into Sleeper IDs and join ESPN/Yahoo IDs, team, position, age, injury/practice and depth-chart metadata. Sleeper recommends refreshing the full map no more than about once per day.

https://api.sleeper.app/v1/players/nfl
Best use: cache once, then filter locally to QB/RB/WR/TE instead of repeatedly downloading the large player map.

Sleeper Actual Stats

THIRD-PARTY DOCUMENTED

Season or weekly actual stats. Useful fields include passing, rushing, receiving, targets, turnovers and fantasy scoring fields. Week is optional.

https://api.sleeper.com/stats/nfl/2025?season_type=regular
https://api.sleeper.com/stats/nfl/2025/1?season_type=regular

Sleeper Projections

THIRD-PARTY DOCUMENTEDSEASON + WEEK

Projected raw football stats and fantasy points. No week = season projection; /1 = Week 1, /2 = Week 2, etc. Can also request a single player by Sleeper ID.

https://api.sleeper.com/projections/nfl/2026?season_type=regular
https://api.sleeper.com/projections/nfl/2026/1?season_type=regular
https://api.sleeper.com/projections/nfl/player/PLAYER_ID?season=2026&season_type=regular&grouping=season

Sleeper Depth Chart

THIRD-PARTY DOCUMENTED

Team depth chart by abbreviation. The player directory also exposes depth_chart_position and depth_chart_order, so either source can be useful.

https://api.sleeper.com/players/nfl/PHI/depth_chart

Sleeper Trending

OFFICIALNO AUTH

Live add/drop momentum. Great for a waiver-wire or draft-buzz signal. Change add → drop and tune lookback_hours/limit.

https://api.sleeper.app/v1/players/nfl/trending/add?lookback_hours=24&limit=25

Sleeper League / Draft

OFFICIAL

If a league ID is supplied: scoring settings, roster positions, rosters, users, weekly matchups and league drafts. Draft IDs then expose every actual pick.

https://api.sleeper.app/v1/league/LEAGUE_ID
https://api.sleeper.app/v1/league/LEAGUE_ID/rosters
https://api.sleeper.app/v1/draft/DRAFT_ID/picks

ESPN

CURRENT APP SOURCE

Keep ESPN historical actuals and 2026 projections as a second data source. Cross-provider comparison is valuable when ESPN and Sleeper disagree on usage or projected production.

Potential derived signal: ESPN projection vs Sleeper projection delta for REC, YDS, TD and custom fantasy points.

Yahoo + Draft Sharks

RESEARCH

Yahoo: ADP/draft-analysis is useful, but a clean public raw projection endpoint remains unresolved. Draft Sharks: floor/ceiling, SOS, injury risk and proprietary projection data are attractive, but do not treat them as an established free API.

How to investigate: desktop Chrome/Safari → DevTools → Network → Fetch/XHR → reload rankings/player page → inspect JSON responses for api, rank, proj, player or graphql. On iPhone, use Safari Web Inspector from a connected Mac. Do not bypass authentication or subscription controls.

High-value data still worth adding

ADP + ADP movement — compare market draft cost against ESPN/Sleeper projected value.
Vegas player props — passing/receiving/rushing yard and TD expectations can become an independent projection signal.
Usage — snaps, routes, targets, target share, carries, red-zone work and goal-line opportunities.
Availability — injury designation, practice participation, depth movement and recent transactions.
Context — opponent strength, weather, implied team total, offensive line and pace.
Projection consensus — ESPN vs Sleeper vs any legitimately accessible third source; show range and disagreement.
