Microsoft Graph setup

You need a Microsoft Entra Application (client) ID. You can create a new registration or reuse an existing one such as Mail Trail.

  1. Open Microsoft Entra admin center.
  2. Go to Entra ID → App registrations.
  3. Open an existing registration or click New registration.
  4. For Hotmail/Outlook.com, make sure supported account types include personal Microsoft accounts.
  5. On Overview, copy Application (client) ID.
  6. Go to Authentication → Add Redirect URI → Single-page application (SPA).
  7. Add the exact redirect URI shown below. Keep any existing iOS/macOS redirect URI.
  8. Go to API permissions → Add a permission → Microsoft Graph → Delegated permissions.
  9. Add User.Read, Mail.ReadWrite, and Mail.Send.
  10. Return here, paste the client ID, click Save client ID, then Sign in.

No client secret: browser SPAs use public-client OAuth/PKCE. The client ID is not a password.
