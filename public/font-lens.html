Match typography from an image, or inspect a live website's font families, weights and sizes. All analysis happens in your browser.

1. Upload an image

PNG, JPG, WebP or a screenshot. You can also paste an image from the clipboard.

2. Select the text

Drag a rectangle tightly around one line of text. Avoid photos, borders, icons and other nearby text.

Your uploaded image appears here

Blue outline = sample area used for matching. Drag again to replace the selection.

3. Identify the typeface

Enter the exact letters shown inside the selection. Optional OCR can fill this in automatically.

Image matching compares letter shapes against a curated set of 70+ fonts. It provides approximate visual matches, not forensic proof of a specific font. Logos, complex backgrounds and modified letters may need manual comparison.

1. Open the website

The inspector reads the page's actual computed CSS. It works with live sites, including ones that block cross-origin fetching.

2. Install the inspection bookmarklet

This tiny bookmark runs on the website itself, avoiding browser cross-origin restrictions. No extensions or API keys needed.

Show your browser's bookmarks bar (Ctrl/Cmd + Shift + B in Chrome).
Drag the button below onto the bookmarks bar.
On the target website, click that bookmark. If opened from this app, the report should appear automatically.
